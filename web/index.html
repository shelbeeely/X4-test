Xteink X4 Debug Firmware

Display bring-up / debug build for the Xteink X4 (ESP32-C3)

Flashes the latest CI build straight from Chrome over WebSerial — no drivers, no command line, nothing to install.

Requires Chrome or Edge on a computer (a Chromebook works fine), with the X4 connected over USB. Web Serial isn't available in mobile browsers.

Your browser doesn't support Web Serial — open this page in Chrome or Edge instead. This page needs to be served over HTTPS to flash (it is here — try reloading).

After flashing

Reopen the install dialog and choose Logs & Console (or click Connect & Flash again and cancel the install step) to get a Web Serial terminal at 115200 baud. You'll see the boot-time BoardConfig pin dump, display geometry, the initial refresh timing, then a line every 5 seconds as the firmware toggles the panel black/white, logging BUSY pin state and refresh duration.

Built automatically on every push by GitHub Actions. See the repo README for manual esptool-js / ESPHome Web flashing instructions and the firmware source.
